# Английские тексты, которые ждут Николая

В `messages/en.json` по-английски только то, что уже утверждено в бизнес-плане:
`Custom-coded websites in 14 days. Fixed price, no templates, support included.` Из этой фразы
собраны заголовки hero всех пяти направлений (`hero.*.title`) и общий `hero.subtitle`.

Остальные ключи в `en.json` — русские заглушки. Claude их не переводит: перевод пишет Николай.

| Ключ                     | Сейчас в `en.json`                                                  |
| ------------------------ | ------------------------------------------------------------------- |
| `meta.title`             | собран из утвержденной фразы, проверить формулировку                |
| `controls.theme`         | русская заглушка «Сменить тему»                                     |
| `nav.*`                  | русские заглушки (Услуги, Кейсы, Цены, Процесс, Контакты)           |
| `header.cta`             | русская заглушка «Обсудить проект»                                  |
| `header.kicker`          | русская заглушка «Студия веб-разработки»                            |
| `header.location`        | русская заглушка «Калининград → весь мир»                           |
| `header.founded`         | русская заглушка «Основана в 2026»                                  |
| `hero.*.lead`            | русские заглушки — вторая фраза hero в каждом направлении           |
| `hero.*.primaryCta`      | русские заглушки («Рассчитать стоимость», `./рассчитать-стоимость`) |
| `hero.*.secondaryCta`    | русские заглушки («Смотреть кейсы», «Читать кейсы», `./кейсы`)      |
| `hero.kinetic.badge`     | русская заглушка                                                    |
| `hero.kinetic.ticker.*`  | русские заглушки — бегущая строка Kinetic                           |
| `hero.terminal.logTitle` | русская заглушка — заголовок панели `build.log`                     |
| `hero.terminal.day`      | русская заглушка «[день {day}]»                                     |
| `hero.terminal.log.*`    | русские заглушки — строки журнала в панели Terminal                 |
| `hero.terminal.status.*` | `ok` общий, «активна» — русская заглушка                            |
| `hero.pop.stickers.*`    | русские заглушки — стикеры Pop                                      |
| `hero.swiss.sectionMark` | русская заглушка «01 — Студия»                                      |
| `hero.editorial.title`   | в RU «за две недели», в EN — утвержденная фраза «in 14 days»        |
| `hero.editorial.quote*`  | русские заглушки — цитата «Из договора» и три ссылки                |
| `switcher.label`         | русская заглушка «Стиль» (пилюля переключателя)                     |
| `footer.heading`         | русская заглушка «Обсудить проект»                                  |
| `footer.headingQuestion` | русская заглушка «Обсудить проект?»                                 |
| `footer.invitation`      | русская заглушка                                                    |
| `footer.telegram`        | русская заглушка «Написать в Telegram»                              |
| `footer.replyTime`       | русская заглушка                                                    |
| `footer.sectionMark`     | русская заглушка «04 — Контакт»                                     |

Правило на будущее: новый ключ появляется сразу в `ru.json` и `en.json`; если английского
текста нет — в `en.json` кладется русская строка и строка добавляется в эту таблицу.
